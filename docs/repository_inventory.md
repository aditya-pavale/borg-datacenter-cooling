## Source (`src/`)

| File | Purpose |
|---|---|
| `data/inspect_borg.py` | Reproducible Phase-1 audit script (produces `docs/dataset_summary.json`). |
| `data/verify_raw_integrity.py` | Raw-data immutability guard, called by every downstream script. |
| `data/clean_borg.py` | Parses/types/trims the raw CSV. |
| `data/aggregate_workload.py` | Zone assignment + temporal binning + the workload-signal aggregation. |
| `data/split_workload.py` | Chronological train/val/test split. |
| `forecasting/dataset.py` | Causal windowing utility (`make_windows`), used by both baselines and the GRU. |
| `forecasting/baselines.py` | Persistence and moving-average forecasters. Referenced by `train_forecaster.py` and exercised directly by `tests/test_forecasting.py`; not previously name-dropped in prose docs, corrected here. |
| `forecasting/gru_model.py` | The GRU forecaster (PyTorch `nn.GRU` + linear head). |
| `forecasting/train_forecaster.py` | Trains/evaluates the GRU against baselines; produces `models/forecasting/*` and `results/forecasting/*`. |
| `thermal/power_model.py` | CPU utilization → IT power → heat (documented simulation assumption). |
| `thermal/thermal_model.py` | The 3-zone coupled lumped-parameter thermal model. |
| `environment/cooling_core.py` | The shared simulation core (physics + reward + safety shield wiring) used by every controller. |
| `environment/single_agent_env.py` | Gymnasium wrapper around `CoolingCore` for single-agent PPO. Not previously name-dropped in prose docs (referenced structurally via `docs/marl_design.md`'s "SingleAgentCoolingEnv" mentions); corrected here. |
| `environment/multi_agent_env.py` | Multi-agent wrapper around the same `CoolingCore`, used by MAPPO. Same note as above. |
| `environment/safety_shield.py` | Exact, closed-form one-step-ahead safety correction. |
| `controllers/classical.py` | Fixed, Threshold, PID, and random-shooting MPC controllers. |
| `controllers/rl_adapters.py` | Adapts trained PPO/MAPPO policies to the same `.act(obs)` interface as classical controllers, for fair evaluation. Not previously name-dropped in prose docs; corrected here. |
| `marl/networks.py` | `GaussianActor` (parameter-shared, decentralized) and `CentralizedCritic`. |
| `marl/mappo.py` | The custom MAPPO training loop (rollout collection, GAE, clipped-surrogate update). |
| `evaluation/metrics.py` | Per-episode and cross-episode metric computation, identical for every controller. |
| `evaluation/run_controller.py` | The fairness-enforcing evaluation harness. |

`src/rl/` existed as an empty, unused directory (leftover project
scaffolding — single-agent PPO uses Stable-Baselines3 directly and
MAPPO lives in `src/marl/`, so nothing was ever placed here). It
contained zero files and was referenced by nothing; **removed** during
this handoff audit (logged in `docs/experiment_log.md`).

No `__init__.py` files exist anywhere under `src/`; Python 3's implicit
namespace-package support makes `sys.path.insert(0, ".../src")` +
`from data.x import y`-style imports work without them. This is
intentional, not an oversight, and every module that needs it performs
that `sys.path.insert` itself.
